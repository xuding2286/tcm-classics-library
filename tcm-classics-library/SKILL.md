# 本地中医古籍书库

## 已知位置与访问

默认书库位于 `/Volumes/Lacie/和青叔中医赴美`：

- 原 PDF：`中医古籍抄本/`
- 文字版：`中医古籍抄本_Markdown/`
- 现有索引：`中医古籍抄本_Markdown/转换目录.md`
- 单本路径通常为 `中医古籍抄本_Markdown/<书名>/<书名>.md`。

先验证路径和文件实际存在，再读取索引。曾核实有 33 本 PDF 及对应文字版；数量、页数和转换状态必须以本次检查为准，不把历史清单当作当前事实。书库不在 Skill 内，不复制整库到 Skill。

路径失效时先查看已挂载磁盘、用户指定位置，或用 `mdfind -name`、`rg --files` 搜索书名和“中医古籍”目录。排除 `._` 文件、回收站和系统缓存，避免无边界扫描全文。已有读取权限时直接继续；确实无法访问时说明具体问题，请用户连接硬盘、选择可访问文件夹或上传所需文件，不假称已经读到内容。

在此 Vault 开始任务前读取 `00_个人背景/定位总览_v0.1.md`；涉及中医内容同时读取 `00_个人背景/小红书内容发布合规规则_v0.1.md`。遵循适用的 AGENTS.md。普通古籍检索不读取 docs/、skill-source/ 等开发辅助目录。

## 查找与阅读

- 用户只要求调取书库时，核实目录、读取书目、抽查文字并交付可点击索引及格式说明；不要求用户先选书才能开始。
- 指定书名时，用 `rg --files` 定位，先读标题、目录或相关章节，再深入正文，避免只读系列共用前言就声称已经读完该书。
- 按词句或主题查找时，优先对文字版使用 `rg -n -F`。多词用多个 `-e`；若无结果，可尝试简繁、异体、断行等合理变体，交代扩展词。零命中仅意味着当前文字版未检出，不证明原书没有。
- 搜索结果先排除前言、目录、页眉造成的伪命中，再读上下文；跨书归纳必须分别阅读所引各书的正文，不把同一套书共用前言当作独立证据。
- 只读取 Markdown 时不必启动 PDF 转换流程。需核对原页或读取仅有 PDF 的资料时，使用可用的 PDF 阅读能力；新建转换文件只在用户要求转换或保存时进行。

## 文本可靠性与引证

现有文字版为文字层提取，目录说明未做 OCR 或人工校勘。已发现数字映射成“员”“圆”等汉字、竖排页眉和断行；转换报告中的 dense math 可能由竖排版式触发，不等于存在数学公式。

- 原文摘录、现代释义、个人归纳和待核查信息分开表达。不得凭语感悄悄修复乱码或补全缺字。
- 数字、年代、剂量、方药、专名及需要准确引用的原句，核对原 PDF；无法核对则保留疑点并标注“文字版提取，未核对原页”。
- 每项实质摘录或结论标明具体书名、章节（可确认时）、可点击的绝对文件路径和已核实的文字行号。行号不冒充书页。
- 标注 PDF 阅读器页序时说明“PDF 第 X 页”；书内印刷页码另行注明，未确认时不编造页码。文字版不保证保留原 PDF 页边界。
- 引用量服从任务需要，不因古籍年代久就默认现代点校、注释、译文和整本排印本均无版权限制。

## 交付与范围

根据请求交付书目索引、相关段落摘录、单书摘要或跨书对照。优先呈现回答，再附简短来源与文本质量说明；内容过多时说明实际阅读和检索范围，不声称全库通读。

默认只读。用户仅要求检索时，不新建文件、不覆盖既有索引、不移动或删除原书。用户要求保存时只新增指定范围的成果，已有同名文件先检查，未经明确要求不覆盖。

私人古籍阅读与学习整理不自动转成公开内容；不提供针对个人症状的诊断、方药或针灸方案，不把历史记载当作现代疗效证据。若用户另行要求选题或发布稿，重新执行 Vault 的用户决策句、选题门槛和发布前合规检查，不能把本 Skill 的检索结果直接当成已过审稿件。
